# 트레이딩 데스크

나만의 가상 거래소입니다. GitHub Pages로 띄우고, 기록은 비공개 저장소 `tsb7-paper`의 `desk/` 폴더에 저장합니다.

- **페이지:** 위쪽 탭으로 넘깁니다 — **거래**(차트·호가·주문·일지) · **시황**(숫자 시황 + 아침·저녁 브리핑) · **성과**(내 계좌·Claude·TSB7 봇 비교, 주간 매매 평가) · **봇**(TSB7 가상매매) · **스크리너**(업비트 급변 후보). 주소 끝 `#mkt` 처럼 남아서 새로고침해도 그 페이지가 열립니다.
- **차트:** '포지션 차트' — 1분~주봉, 지표(이동평균·볼린저·돈치안·켈트너·일목·SAR·슈퍼트렌드·VWAP, 아래 칸 RSI·MACD·스토캐스틱·스토캐스틱 RSI·ATR·ADX·CCI·윌리엄스 %R·MFI·Williams Vix Fix·WaveTrend·OBV 최대 4개), 수평선·추세선·피보나치, 구간 측정(Shift+끌기 또는 '측정' — 가격 차·%·봉 수·기간), 로그 눈금, 이미지 저장. 손절·익절·대기 주문 선은 오른쪽 손잡이를 끌어 옮기고 × 로 지웁니다 (내 진입가·손절·익절·청산가·대기 주문 선, 체결 표시, 이평·볼린저·거래량, 아래 칸 RSI·MACD, 수평선·추세선 그리기 — 내 선은 계좌 기록에 저장돼 다른 기기에서도 보임)와 트레이딩뷰 위젯을 전환합니다. 트레이딩뷰 위젯에는 바깥에서 선을 넣을 수 없어 내 선은 포지션 차트에만 보입니다.
- **실시간 시세·호가:** 모두 바이낸스 — 현물 USDT 마켓, USDT 무기한 선물
- **종목:** 기본 8개 (BTC ETH XRP SOL DOGE ADA LINK NEAR). 오른쪽 위 ⚙ 설정에서 바이낸스 USDT 마켓에 있는 이름으로 바꿀 수 있습니다.
- **주문:**
  - 현물: 매수·매도
  - 선물: 롱·숏, 레버리지 1~125배(격리), 펀딩비 8시간마다
  - 시장가 · 지정가 · 조건(돌파·이탈), 손절·익절
  - 손절·익절은 가격 또는 진입가 ±% 로 입력 (보유 중에는 ROE % 도)
  - 포지션 종료: 시장가·지정가, 25·50·75·100% 또는 직접 비율 (지정가는 청산 전용 대기 주문)
- **놓친 체결:** 화면을 닫아 둔 동안 지정가·손절·익절·강제청산 가격에 닿았으면, 다시 열 때 그 사이 캔들(5분봉)의 시가·고가·저가로 확인해서 체결합니다.
  - 한 캔들에 손절과 익절이 모두 닿으면 손절로 처리합니다.
  - 시가가 이미 더 불리한(또는 유리한) 곳에서 시작하면 시가로 체결합니다.
- **매매 일지:** 진입할 때 셋업·감정·이유를 남기고, 청산 뒤 돌아보기와 규칙 준수 여부를 기록합니다.
  - 통계 탭에서 셋업별·감정별 승률, 손익비, 거래당 기대값(USDT와 R)을 보여 줍니다.
  - 100회 진행률도 함께 보여 줍니다.
- **Claude 계좌·브리핑:** 매일 09:20(아침, 진입 판단)·21:20(저녁, 관리만) 예약 실행되는 Claude 가 `desk/BRIEFING.md` 지침대로 브리핑을 쓰고 `desk/claude/orders.json` 에 주문을 넣습니다. 가상매매 봇(GitHub Actions)이 4시간마다 15분봉으로 체결을 계산하고 숫자 시황(`desk/market.json`)을 만듭니다. 매주 일요일 20:40 에는 `desk/REVIEW.md` 지침대로 내 매매 일지 평가가 `desk/reviews/` 에 올라옵니다.
- **봇 계좌:** `paper/*/equity.csv`와 일일 대조(`paper/reconcile.csv`)를 보여 줍니다. A~D (TSB7 계열), E·F (급락 매수 — '급락' 표시, 제때 했다면 방식), BH·BF (기준선 — '기준' 표시, 예전 H·F). 성과 탭 비교에도 E·F 포함.
- **스크리너:** 업비트 원화 종목 중 그날 09시부터 크게 움직일(위든 아래든) 종목 10개를 전날 21시·새벽 6시에 미리 고르고, 정오(±10%)·다음날 9시(±20%)에 실제로 움직였는지 자동 채점해 누적 적중률을 보여 줍니다.
  - 만드는 곳: `tsb7-paper`의 `desk/screener.py` + `.github/workflows/screener.yml` (21:06·06:06 목록, 12:08·09:38 채점, 30분 뒤 예비 실행)
  - 모델: `desk/screener/model.json` = 연구 코드 `vol_lab.py export-model` 결과 (업비트 1시간봉 재료 19개 · 로지스틱). 파일이 없으면 '20일 변동성 순'으로 임시 운영합니다.
  - 방향은 모델이 모릅니다. 종목별 김프·바이낸스 24시간으로 만든 약한 방향 힌트를 따로 표시하고 그것도 채점합니다.

## 설치 (한 번만)

1. **공개 저장소 `trading-desk` 만들기**
   - 무료 계정의 GitHub Pages는 공개 저장소에서만 됩니다. 여기에는 화면 코드만 올리고, 기록은 비공개 `tsb7-paper`에 둡니다.
   - `index.html`, `engine.js`, `app.js`, `README.md`를 올립니다.
2. **Pages 켜기:** Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save
   - 1~2분 뒤 `https://<아이디>.github.io/trading-desk/` 에서 열립니다.
3. **`tsb7-paper` 저장소에 `desk/` 폴더 올리기**
   - 올릴 파일: `engine.js`, `claude_engine.js`, `claude/orders.json`, `briefings/index.json`
   - 워크플로 파일 `.github/workflows/paper.yml`도 새것으로 교체합니다. Claude 계좌 체결 단계가 추가됐습니다.
4. **화면용 토큰 만들기**
   - GitHub → Settings → Developer settings → Fine-grained tokens
   - Repository access는 `tsb7-paper` 하나만 고릅니다.
   - Permissions → Repository permissions → **Contents: Read and write**를 줍니다.
   - cron-job.org에 쓴 토큰(Actions 권한)과는 따로 만드는 걸 권합니다.
5. **화면에서 연결:** 오른쪽 위 ⚙ 설정 → 저장소 주인(아이디) · `tsb7-paper` · `main` · 토큰 → "저장하고 연결"
   - 폰에서도 같은 방법으로 한 번 연결하면, 폰과 PC가 같은 계좌를 봅니다.

## 알아둘 점

- 토큰은 그 기기의 브라우저에만 저장됩니다. 공용 PC에서는 넣지 마세요.
- **"놓친 구간 확인 실패"가 뜰 때:** 브라우저가 바이낸스 REST API를 막은 경우입니다(광고 차단기, 회사망 등). 1분 뒤 자동으로 다시 시도합니다. 그때는 실시간 체결만 반영되고, 다음에 열 때 다시 확인합니다.
- **Claude 계좌의 가격:** GitHub 서버(미국)에서는 바이낸스 API가 막혀 있어서, 바이낸스 공개 시세 미러(data-api.binance.vision)의 현물 USDT 가격으로 계산합니다. 선물도 이 현물 가격을 쓰므로 차이는 보통 0.1% 안쪽이고, 펀딩비는 반영하지 않습니다.
- **v2 이전(원화 현물) 계좌:** 처음 열 때 현물만 1만 USDT로 새로 시작하고 선물 기록은 그대로 둡니다. 예전 기록은 브라우저의 `desk.me.v1`에 남겨 둡니다. Claude 계좌도 같은 이유로 새로 시작하고, 예전 상태는 `desk/claude/state.v1.json`에 남깁니다.
- **가상매매 봇(TSB7)은 그대로 업비트 원화입니다.** 실제로 돈을 넣을 거래소 기준으로 검증한 전략이라 바꾸지 않았습니다. 봇 계좌 탭의 금액은 원입니다.
- **`engine.js`는 두 곳에 같은 파일이 있습니다** (`trading-desk/engine.js`, `tsb7-paper/desk/engine.js`). 바꿀 때는 둘 다 바꿔야 화면과 Claude 계좌가 같은 규칙으로 체결됩니다.
